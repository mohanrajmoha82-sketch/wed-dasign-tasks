python-Based online Examination and Recrultement system

Project Description

The Python-Based Online Examination and Recruitment System is a desktop application developed using Python and Tkinter that helps users prepare for technical interviews, attend online examinations, search jobs, and generate certificates. The system provides multiple subject-based exams such as Python, Java, AI Engineer, UI/UX, Web Development, and Django.

It also includes user registration, login, profile management, job searching, certificate generation, and result management. The application stores user information and examination data in a MySQL database.
